# Node.js × MySQL Webアプリ

## 概要

Node.jsとMySQLを利用したWebアプリケーションです。
データベースとの接続やCRUD処理を学ぶことを目的として制作しました。

## 使用技術

- Node.js
- Express
- MySQL
- HTML
- CSS
- JavaScript

## 主な機能

- データ登録
- データ一覧表示
- データ編集
- データ削除

## 実行方法

1. npm install
2. MySQLを起動
3. データベースを作成
4. npm start
